The story

散落的想法，值得被收成一束光。

拾光是一个虚构的 AI 工作台：把便签、聊天和文档里的碎片，连成一份能执行的计划。这支片子用同一个隐喻讲它——从散落，到清晰。

01

一百个想法

开场是 30 张漂浮的便签，它们不是贴图，是 DOM；每一张的位移、旋转和透明度都是时间的函数。

02

收成一束光

便签向中心收拢，变成一条竖线，再长成一个标记。没有转场插件，只有位置和缩放的插值。

03

从散落到清晰

左侧的混乱与右侧的计划同屏对照。最后 5 秒，所有声音一起收束到一句品牌主张。

The method

不是剪辑，是代码。

codefilm 是一个可移植的 agent skill：给它一条参考视频或一个主题，它先判断能不能用代码重建，再逐帧验证，不把“看起来像”当成“做对了”。

01 / ROUTE

先判断

平面动效、UI、字、图表 → 代码。真人、实拍、复杂 3D → 生成或剪辑。不承诺做不到的事。

02 / ANALYZE

量出来

切点、镜头长度、静止比、运动强度、调色板、语气。形容词全部换成数字。

03 / BUILD

写成代码

一个 HTML，一个 render(t)。没有 CSS 动画、没有随机数、没有墙钟时间。

04 / VERIFY

逐帧对

并排帧差、确定性、循环缝、节奏与音频 oracle。通过才交付。
